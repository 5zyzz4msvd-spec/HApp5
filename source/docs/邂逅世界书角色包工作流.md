# 邂逅角色包世界书整理工作流

目标：把用户提供的世界书 JSON 中的动态角色条目整理成邂逅角色包。抽取对象只包括：

- `{名字}人设`（兼容旧版 `[mvu_plot]{名字}人设`）
- `[mvu_update]{名字}变量`

排除默认三人：

- 西园寺爱丽莎
- 犬冢夏美
- 月咏深雪

## 关键原则

1. 不手工猜世界书布局。
2. 人设和变量世界书的 `order`、`insertion_order`、`depth`、`position`、`role`、`extensions` 必须保留并记录。
3. 默认三人的同类条目是模板：导出给邂逅的条目布局优先套用默认三人的变量/人设条目布局。
4. 原始条目布局也要写入报告，方便人工核对。
5. 角色图片提示词必须保持统一画风，先一行一角色给用户，等待用户回传图片后再打包。

## 第 1 步：用户传世界书 JSON

用户把当前角色卡世界书 JSON 发给 Codex，或放入工作区，例如：

```bash
tmp/worldbook.json
```

## 第 2 步：静态脚本抽取角色

运行：

```bash
npm run prepare:encounter-worldbook -- tmp/worldbook.json --out tmp/encounter-worldbook-package --package-name "邂逅扩展角色包"
```

脚本会生成：

- `tmp/encounter-worldbook-package/package.json`
- `tmp/encounter-worldbook-package/roles/{角色名}/role.json`
- `tmp/encounter-worldbook-package/roles/{角色名}/persona-entry.original.json`
- `tmp/encounter-worldbook-package/roles/{角色名}/persona-entry.encounter-layout.json`
- `tmp/encounter-worldbook-package/roles/{角色名}/variable-entry.original.json`
- `tmp/encounter-worldbook-package/roles/{角色名}/variable-entry.encounter-layout.json`
- `tmp/encounter-worldbook-package/layout/worldbook-layout-report.json`
- `tmp/encounter-worldbook-package/prompts/role-image-prompts-oneline.txt`

重点检查：

- `layout/worldbook-layout-report.json` 里的默认三人模板是否存在。
- 每个角色是否同时有 `persona` 和 `variable` 条目。
- `encounterLayouts` 的 `order/depth/position/role/extensions` 是否和默认三人同类条目一致。

## 第 3 步：把图片提示词一次性发给用户

Codex 读取：

```bash
tmp/encounter-worldbook-package/prompts/role-image-prompts-oneline.txt
```

然后把每个角色的一行图片提示词发给用户。要求：

- 每个角色一行。
- 统一风格。
- 证件照样式，腹部以上。
- 纯白或浅灰背景。
- 不生成复杂背景、多人、文字。

用户把这些提示词转交给 GPT / 图片模型生成图片。

## 第 4 步：等待用户回传图片

用户把图片放入一个目录，例如：

```bash
tmp/encounter-worldbook-package/images/
```

图片命名优先使用角色名：

```text
角色名.png
角色名.jpg
角色名.webp
```

## 第 5 步：带图片重新生成目录与 ZIP

运行：

```bash
npm run prepare:encounter-worldbook -- tmp/worldbook.json \
  --out tmp/encounter-worldbook-package \
  --package-name "邂逅扩展角色包" \
  --images tmp/encounter-worldbook-package/images \
  --zip tmp/encounter-worldbook-package.zip
```

角色包不再要求总的 AI 邂逅提示词；每个角色的登场方式应放在角色人设或角色级出场提示里。

## 第 6 步：导入邂逅

在前端邂逅应用中导入：

```bash
tmp/encounter-worldbook-package.zip
```

然后在邂逅里浏览角色包，确认：

- 角色包名称、介绍、价格正确。
- 每个角色有图片。
- 每个角色的人设内容完整。
- 随机桃花运命中角色时，会写入当前角色卡世界书。
- 世界书条目的顺序、深度、位置按默认三人模板执行。

## 故障排查

- 缺少默认三人模板：检查 JSON 里是否还保留西园寺爱丽莎、犬冢夏美、月咏深雪的人设 / `[mvu_update]` 变量条目；旧版 `[mvu_plot]` 人设仍可被脚本识别。
- 某角色只有人设没有变量：脚本仍会整理，但报告里会标记缺失，需要人工确认是否允许前端固定变量 entry 补齐。
- 图片没挂上：检查图片文件名是否包含角色名，或用 `roles/{角色名}/role.json` 里的 `image` 字段手动确认。
- 导入后顺序/深度异常：优先看 `layout/worldbook-layout-report.json` 的 `templateLayouts` 和 `encounterLayouts`。
